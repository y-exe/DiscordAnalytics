# ステータス・案内用絵文字

tokumei-botと同じ素材を128×128pxのPNGとして同梱している。
起動時に本Botアプリのアプリケーション絵文字へ登録する (名前は `da_*`、既存登録は再利用)。

| ファイル | 絵文字名 |
| --- | --- |
| check.png | da_check |
| flag.png | da_flag |
| warning.png | da_warning |
| info.png | da_info |
| error.png | da_error |
| time.png | da_time |
| content.png | da_content |
| count.png | da_count |
| reporter.png | da_reporter |

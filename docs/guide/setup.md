# 初期設定

[目次](../README.md)

これらのコマンドは「サーバー管理権限 (サーバー管理 / 管理者) を持つメンバー」「サーバー所有者」「Bot管理者」のみ実行できます。Bot管理者は `BOT_ADMIN_ID_URL` (既定: `https://yexe.net/discord/id`) から取得し、`BOT_ADMIN_IDS` 環境変数をフォールバックに使えます。

## ギルド設定 — `/setup`

`/setup` 1つで全設定を管理します。実行すると現在の設定一覧を Components V2 の埋め込みで表示し、ボタンで各セクションへ移動します。変更はすべて即時に反映されます。

| セクション | 対応 |
| --- | --- |
| 発言王ロール | 月間発言王ロールを設定・解除 (ロール選択メニュー) |
| 除外チャンネル | ランキング除外チャンネルの追加・解除・全消去 (チャンネル選択メニュー) |
| その他の集約 | 指定カテゴリ配下をWebサイトで1チャンネルに集約。表示名 (「その他」→「プラチャ」など) も変更可 |
| Web表示 | サイドバー表示を「すべて表示 / ホワイトリスト / 一部を隠す」の3モードで制御 |
| 告知先 | 月間ランキングの告知先チャンネルを設定・解除 |
| ドメイン | 標準サブドメインの再登録、招待コード・独自ドメインの追加 (モーダル入力) |

設定は `guilds` テーブルに保存され、`GUILD_ID`・`KING_ROLE_ID`・`ANNOUNCE_CHANNEL_ID`・`EXCLUDED_CHANNEL_IDS` の環境変数は既定ギルドのシード値です。起動時に未設定の列だけを埋め、`/setup` による設定を優先します。

Web表示まわりは `guilds.display_config` (JSONB) に保存されます:

| キー | 内容 |
| --- | --- |
| `whitelistChannelIds` | サイドバーに表示するチャンネル。非空ならホワイトリストモード |
| `hiddenChannelIds` | 非表示にするチャンネル (ホワイトリスト未設定時に有効)。サイドバーから消え、個別ページも404 |
| `privateChatCategoryIds` | 集約するカテゴリ。集約チャンネルの仮想IDは `-1` |
| `privateChatLabel` | 集約チャンネルの表示名。未設定なら「その他」 |

## 月間発言王ロール

- 対象は日本時間の前月。Bot起動時と60秒ごとの確認で、発言王ロールを全ギルドへ更新します。
- 完了した月は `monthly_role_runs` に記録され、重複実行を防ぎます。
- 更新失敗時は完了扱いにせず再試行します。Botには対象ロールより上のロールと「ロールの管理」権限が必要です。

## サブドメイン・独自ドメイン

`/setup` → 「ドメイン」セクションから設定します。

- 標準サブドメイン (`[サーバーID].yexe.top`) はBot参加時に自動登録され、削除はできない (独自ドメインのCNAME先として必須)。
- 招待コード (`[コード].yexe.top`) はモーダルでコードを入力して設定。ケースセンシティブです。
- 独自ドメインは `CNAME → [サーバーID].yexe.top` を向けてください (必ずCNAME。VPSのIPを直接指定しない)。

- 登録済み (かつ有効) ドメインだけがCaddyのon-demand TLSで証明書を発行されます (`/api/internal/caddy-ask` が `guild_domains` テーブルで判定)。ask元の認可には `CADDY_ASK_TOKEN` (Caddyfileのask URLに `?token=` で渡す、SOPSで管理) を使う。
- DNSをVPSに向けてからダッシュボードへアクセスすると、証明書発行が走ります。発行に失敗する場合はDNS伝播と `guild_domains` の有効フラグを確認します。
- 無料サブドメインは失効チェッカー (6時間ごと) が管理します。基準ドメインは `SUBDOMAIN_BASE_DOMAIN` (既定: `yexe.top`)。
- apex (`yexe.top` 自体) はテナント名前空間の対象外です。

## Bot コマンド

| コマンド | 内容 |
| --- | --- |
| `/setup` | 【管理者用】全設定の管理画面 (Components V2) |
| `/month` | 【管理者用】指定した月のランキングを手動送信 |
| `/all` | 【管理者用】全期間のランキングを表示 |

月間ランキングは毎月、告知先チャンネルへ自動投稿されます。投稿に含まれるリンクはそのサーバーのダッシュボードURL (登録ドメイン優先) です。
